# FareFinder (نموذج إحالة بدون ترخيص وكالة)
موقع مقارنة أسعار طيران. لا يبيع تذاكر ولا يستلم دفعاً: زر "اذهب للحجز" يحوّل المستخدم لموقع الشريك (Aviasales عبر Travelpayouts) بعلامتك (marker) وتربح عمولة.

تشغيل: `node src/server.js` (Node 18+) ← http://localhost:3000 · اختبار: `npm test`

## متغيرات البيئة
- `TP_TOKEN`: توكن Travelpayouts Data API. بدونه يعمل الموقع بأسعار **تجريبية**.
- `TP_MARKER`: رقم المسوّق (marker) من حسابك. ضروري لاحتساب العمولة.
- `ADMIN_KEY`: يحمي /api/admin/stats (أرسله في ترويسة x-admin-key).
- `COMMISSION_PCT` (افتراضي 0.012): لتقدير الدخل فقط.

## النشر
Render: ارفع المجلد إلى GitHub ← New > Blueprint (render.yaml) ← أضف المتغيرات. أو أي استضافة تدعم Docker/Node. ملاحظة: التخزين ملف JSON ويُمسح في الخطة المجانية عند إعادة التشغيل؛ للإنتاج استخدم قاعدة بيانات.

## غير مختبر
التكامل مع Travelpayouts الحقيقي (لا يوجد توكن)، وصيغة روابط العمولة؛ استخدم روابط لوحة Travelpayouts عند اختلافها.
