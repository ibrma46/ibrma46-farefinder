# التحليل والتصميم

## 1. الفكرة والمستخدم
مقارنة أسعار الطيران من عدة مزودين وعرض الأرخص أولاً، مع رسوم خدمة شفافة تحقق ربحاً.
المستخدمون: مسافرون في السعودية والخليج حساسون للسعر (عائلات، طلاب، عمالة، سياحة داخلية). 

## 2. الخصائص الأساسية
بحث (من/إلى/تاريخ/عدد) · ترتيب بالأرخص · تقويم أرخص يوم (±3 أيام) · دمج نفس الرحلة من عدة مزودين مع الأرخص · حجز · لوحة إحصاءات الأرباح.

## 3. الشاشات
شاشة واحدة RTL: نموذج البحث ← شريط الأيام الأرخص ← قائمة النتائج (شارة "الأرخص") ← نافذة الحجز ← رسالة التأكيد برقم مرجع.

## 4. التقنية
Node.js بدون مكتبات خارجية (لا تثبيت، تشغيل فوري، سطح هجوم أقل) + واجهة HTML/JS صافية + ملف JSON للتخزين. مناسب لنموذج أولي. للإنتاج: PostgreSQL، مزود حقيقي (Amadeus/Duffel/Travelport)، بوابة دفع (Moyasar/Stripe).

## نموذج الربح
سعر العميل = سعر المزود + رسوم خدمة (4% بحد أدنى 15 وأعلى 80 ريال). الربح = الرسوم − تكلفة الدفع (2.9% + 1 ريال). القيم في src/pricing.js.
